Privacy policy

Last updated: 27 November 2026.

Homelab Blender Archive is a personal tool used only by its owner, Kamil Tuktagulov.

Data accessed

The tool requests only the Google Drive drive.file scope. It can see and change only the files and folders it created itself in the owner's Google Drive. It cannot read any other files in that Drive.

Data use and storage

Files are copied between the owner's private home server and the owner's Google Drive and are used for nothing else. The OAuth token is stored only on that server. No data is shared with, sold to, or sent to any third party, and nothing is collected for analytics or advertising.

Revoking access

Access can be revoked at any time in the Google Account under Security, "Third-party apps and services".
